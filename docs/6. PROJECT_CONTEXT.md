## Phase 3 — planned, not implemented

Agreed: local-first USDA catalogue, explicit discovery capped at 10 searches/user/day, separate logical MongoDB food database, manual cleanup and upstream/storage safeguards; no Redis. Original Phase 3 also planned AI label/photo/text/voice input, CSV/JSON exports and scoped external-agent/MCP access. The Phase 2 exclusion did not cancel those items. Provider/privacy/cost/sequence decisions remain open. See [Phase 3 backlog](PHASE_3_BACKLOG.md).

## Phase 4 and later — conditional

[Platform backlog](PHASE_4_BACKLOG.md): durable worker/outbox, broader audit/analytics, notifications, offline/PWA, more identity providers and scaling. Minimum agent authorization/audit must ship with Phase 3 agents, not wait for this platform. Recovery is not promised; release tags are code checkpoints, not database backups.

## Current operations

- Frontend: React/TypeScript/Vite, Cloudflare Workers static assets (`atethat`), not Pages. Wrangler enables SPA fallback and `previews: {}`.
- Frontend: `https://atethat.architsangal.in`; REST: `https://api.atethat.architsangal.in/api/v1`; API health: `/healthz` on the API host.
- API/Core run behind Caddy/Docker Compose on the Hostinger VPS; Core is private. MongoDB Atlas is external. See [deployment](DEPLOYMENT.md).
- Backend deploy workflow runs on push to `main`, using the production environment and restricted VPS SSH command. Cloudflare independently builds/deploys the frontend from Git.
- Vite variables are public build-time values, not secrets or static-Worker runtime bindings; rebuild after changing them.
- Existing `usda_food_cache` stores raw search/detail responses with 24-hour expiry. It is not a persistent catalogue and has no 10-search/user quota.
- FDA reference: `FDA_DAILY_VALUES_ADULT`, `reviewed-2026-10-08`, general benchmarks rather than personalized needs.
- Diary compaction after 90 days is separate from catalogue retention.

## Workflow and verification

Feature branch from `dev` → local verification → PR to `dev` → release PR to `main`. Do not bypass protections, force-push/delete protected branches or infer deployment authority from a documentation request. Preserve user work and keep secrets out of Git, logs and frontend.

Run frontend typecheck/build/model tests, API/Core Go tests and `sh scripts/check-contracts.sh`. Mongo integration requires an isolated replica set; hosted CI does not provision it currently. Linux containers avoid the observed native macOS Go toolchain issue. The Phase 2 smoke script deliberately targets localhost and only its synthetic fixture; never repoint it at production.

Production Chrome sanity used an owner-designated test account with explicit permission. Personal health records remain out of scope without authorization. OpenAPI formalizes 27 operations, not every runtime route; protobuf descriptors are also checked.
