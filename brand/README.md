# AteThat brand resources

## `atethat-google-profile.png`

Square, icon-only profile image for the AteThat Google Account. Upload this file as the Google Account profile picture; its central composition is designed to remain clear in Google's circular crop.

## `atethat-wordmark.png`

Existing AteThat icon-and-wordmark reference exported from the Stitch design. Use it for documentation, presentation, or future brand work where a horizontal logo is appropriate. It is not intended for circular profile-photo crops.

These files are source brand resources. They are not yet wired into the web application.
